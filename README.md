# Unimed Sem Fila — Protótipo v8

Esta versão consolida os ajustes visuais e operacionais definidos após a apresentação do protótipo.

Principais pontos:

- topo do portal ajustado para ficar mais próximo do site oficial em zoom 100%;
- carrossel em proporção 1920x640, sem distorção, com as campanhas fornecidas e novo slide de Agendamento Online;
- área abaixo do carrossel com acessos rápidos;
- IVA substituída pela imagem fornecida;
- botões de acessibilidade interativos;
- chatbox com X para fechar, campo real de digitação, envio por Enter ou seta, seletor de emoji, anexo de arquivos e botões de assuntos;
- novo botão de Agendamento Online destacado no chat;
- fluxo de agendamento revisado;
- identificação por carteirinha ou CPF + nascimento;
- opção para agendar para outra pessoa, com regra LGPD explícita;
- atendimento e repasse de informações somente ao beneficiário agendado ou responsável pelo plano;
- orientação para menor de idade calculada pela data de nascimento;
- beneficiário local ou de intercâmbio;
- segundo assunto no mesmo agendamento;
- reserva de 40 minutos para um assunto e 80 minutos para dois assuntos;
- agenda valida blocos contínuos antes de oferecer o horário;
- cancelamento com no mínimo 2 horas de antecedência;
- painel gerencial com adesão por faixa etária, perfil local/intercâmbio, assuntos, horários, ocupação, múltiplos assuntos e negociações.

## Publicação

Substitua os arquivos do repositório pela versão v8 e envie todos os arquivos da pasta `assets`.
